# Security Policy

## Supported Versions

The latest release and main branch are supported with security updates.

## Reporting a Vulnerability

Do NOT open a public issue. Email security concerns to wojonstech@gmail.com.

We aim to acknowledge reports within 48 hours and provide an initial assessment within 5 business days.

## Scope

- Game server (apps/server)
- Web dashboard (apps/web)
- CLI tools (apps/cli)
- Shared types and FSM (packages/shared)

## Out of Scope

- Legacy monolithic game engine (game-engine.js) — maintained for reference only
- Archive directory
- Third-party LLM provider API keys (managed via .env, never committed)
