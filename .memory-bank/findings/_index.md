# Findings & Self-Improvement Index

**Purpose**: This folder is where agents accumulate findings, recurring patterns, anti-patterns, and self-improvement notes. It is the durable "lessons learned" store.

Agents should write here — NOT into `AGENTS.md` — when they discover something worth remembering. `AGENTS.md` only points to this index.
